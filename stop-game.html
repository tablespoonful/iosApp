10秒止めゲーム

最終更新日: 2026-08-02

選択したレベルに応じて 0.01 秒刻みでカウントし、目標時間ぴったりで止めることを目指すシンプルなゲームです。

主な機能

  • レベル選択（1〜4）
  • 0.01 秒刻みの精密タイマー
  • 目標との誤差を結果表示
  • 記録の保存・共有

プライバシーポリシー

「10秒止めゲーム」は、以下の方針に基づきユーザーの情報を取り扱います。

1. 収集・処理する情報

本アプリのゲーム記録は端末内に保存されます。一方、広告配信、障害解析および設定配信のため、端末識別子、広告データ、製品操作、概算位置情報、クラッシュ情報、パフォーマンス情報、その他の診断情報が Google のサービスにより処理される場合があります。氏名、メールアドレス、ゲーム記録を当方のサーバーへ保存することはありません。

2. 広告について

本アプリは Google AdMob による広告を表示します。AdMob は広告の配信、頻度管理、効果測定および不正防止のため、端末識別子、広告データ、製品操作、概算位置情報、IP アドレス、クラッシュ・パフォーマンス・その他の診断情報を収集・利用する場合があります。利用状況および地域の同意状態に応じて、データが広告目的で Google や広告パートナーに共有される場合があります。本アプリは App Tracking Transparency の許可要求を行わず、IDFA と Publisher first-party ID を使用しません。詳細は Google の広告に関するポリシー をご確認ください。

3. 障害解析と設定配信について

品質改善のため Firebase Crashlytics を使用し、クラッシュ時のスタックトレース、アプリ状態、端末・OS情報および診断情報を処理します。また Firebase Remote Config と Firebase Installations を使用し、国・言語・タイムゾーン・OS・アプリ情報、SDKの動作情報およびアプリインストール識別子を、設定配信とサービス品質の分析のために処理します。Firebase Analytics は使用していません。詳細は Firebase のプライバシーとセキュリティ をご確認ください。

4. 第三者への提供

上記目的の範囲で Google の AdMob および Firebase を利用します。それ以外に、当方がユーザーの個人情報を販売することはありません。

5. プライバシーポリシーの変更

本ポリシーは必要に応じて改定することがあります。重要な変更はアプリ内または本ページでお知らせします。
